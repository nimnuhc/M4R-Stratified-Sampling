# M4R-Stratified-Sampling
This repository contains the numerical experiment implementation for Section 4.5 of the thesis, along with my own drafts and the prompts used with generative AI. All PDFs in this repository are my own drafts, written before any GenAI use with the exception of pD-algorithm_prompt.pdf, which is my own drafted algorithm written using the cleaner notation produced in the Gemini conversation (the logic and algorithm remain my own; only the notation reflects that step). The drafts are included so that the input to each GenAI conversation can be inspected alongside its output.

1. stratified_sampling_numerical_experiments.ipynb: This is the numerical experiments implemented for Section 4.5

2. 1D_Regional sampling_2.pdf: This includes my initial formulation of stratified sampling in 1D and algorithm. This is used as prompt in https://chatgpt.com/share/6a256568-7204-83eb-82b4-1555fc431722 to generate Python implementation following my drafted algorithm in 1D.

3. nD_Regional sampling.pdf: This include my initial formulation of stratified sampling in n-dimensional. This is used as prompt in https://gemini.google.com/share/154849700650 to obtain better notational readibility.

4. pD-algorithm prompt.pdf: This my initial drafted algorithm for p-dimensional stratified sampling using the clean notation as generated in https://gemini.google.com/share/154849700650. This is used as prompt again in https://chatgpt.com/share/6a256568-7204-83eb-82b4-1555fc431722 for generating Python implementation.
